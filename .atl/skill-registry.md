## Project Standards

### Tech Stack
- **Framework**: Next.js 15.1.9 (App Router)
- **Styling**: Tailwind CSS v4 + Vanilla CSS custom variables
- **State Management**: Redux Toolkit & React Redux
- **Database / ORM**: Prisma v7.3.0 & PostgreSQL (Docker Compose)
- **Authentication**: NextAuth v5 (beta)

### Frontend Design System Rules
- **Typography**: Pair distinctive headings (e.g., Space Grotesk) with legible body fonts (e.g., Inter/Geist). Avoid generic system fallbacks.
- **Colors**: Use custom Tailwind HSL-mapped variables (e.g., Electric Violet, Cyan Neon in dark mode). Maintain strong contrast and premium aesthetics (e.g., glassmorphism, glowing micro-shadows).
- **Animations**: Prefer CSS-only animations and transitions. Enhance user experience with micro-interactions on hover, card loads, and page transitions.
